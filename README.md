# SmoothCamV2

SmoothCamV2 is a Roblox script designed to enhance the camera experience in Roblox games by providing smooth transitions between first-person and third-person views. It includes server-side camera control, client-side input handling, and customizable camera settings.

## Install

1. Download the SmoothCamV2 script files from the GitHub repository.
2. Place the `CameraController.server.lua` script in the ServerScriptService.
3. Place the `CameraModule.client.lua` script in the StarterPlayerScripts.
4. Place the `CameraSettings.module.lua` script in the ReplicatedStorage.

## Use

1. Players can switch between first-person and third-person views by pressing the 'F' key.
2. The camera transitions are smooth and customizable through the settings in the `CameraSettings.module.lua` file.
